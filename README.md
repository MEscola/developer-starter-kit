# Developer Starter Kit

Coleção de templates, boas práticas e ferramentas para acelerar a criação de novos projetos.

## Estrutura

```
frontend/   -> Templates para aplicações frontend
backend/    -> Templates para APIs e serviços
devops/     -> Docker, CI/CD, Terraform e infraestrutura
docs/       -> Templates de documentação e arquitetura
examples/   -> Projetos de exemplo utilizando os templates
```

## Objetivos

- Padronizar novos projetos
- Evitar recriar configurações do zero
- Centralizar boas práticas
- Facilitar manutenção e evolução dos projetos
